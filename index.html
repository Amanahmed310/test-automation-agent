Test attachmentsNo files

Azure work-item attachments are fetched automatically. Add DOM files (.html/.txt/.xml/.json), Excel data (.xlsx/.csv), or images. Confirmed scenario values come from attached files; when a sheet has a TestCase ID column, only the exact matching row is used. If data or framework functionality is missing, Smart Generate creates the best draft it can and labels inferred values GUESS or unsupported functionality TODO. The shared framework workbook is only a runtime destination, never a source the generator searches. XLSX context scans up to 5 sheets and 2,000 rows per sheet. Smart Generate sends selected files to your chosen AI CLI and may use more credits/tokens. Images require a vision-capable model. File data stays in memory for up to 1 hour; temporary prompt/image files are removed after generation.
